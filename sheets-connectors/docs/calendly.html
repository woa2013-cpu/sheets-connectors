Calendly to Google Sheets (free script)

Pulls your Calendly bookings into a sheet called Calendly bookings, one row per invitee: event time, event name, status, name, email, time zone, booked-at time, cancellations (who and why), reschedules, no-shows, location, UTM source/medium/campaign, and every booking question as its own column. It uses Calendly's API, which is available on every plan, including Free. You don't need CSV export or Zapier.

A one-click Pro version is planned ($9/month, with a free tier for small accounts). Join the waitlist.

Set it up (about 3 minutes)

  1. Open the Google Sheet you want to use, then choose Extensions > Apps Script.
  2. Delete the sample code, paste the script from the GitHub repository (calendly/Code.gs), and click Save.
  3. Reload the spreadsheet. A Calendly Sync menu appears.
  4. Choose Calendly Sync > Connect Calendly and paste a personal access token. Create one in Calendly under Integrations & apps > API and webhooks.
  5. Choose Calendly Sync > Sync now. The first time, Google asks you to authorize the script. It only asks to edit the current spreadsheet, connect to Calendly's API and run on a schedule.

Good to know

  • The default sync covers the last 30 days and the next 60 days. Use Sync a custom date range for anything else.
  • Turn on hourly sync keeps the sheet current automatically.
  • On the free plan Calendly allows 50 API requests per minute. The script slows down automatically to stay within it. A very large first sync (hundreds of events) may need to be split into smaller date ranges.
  • Times are shown in your spreadsheet's time zone (File > Settings).

Privacy

Your token is saved in your own Apps Script user properties. Use Disconnect in the menu to delete it. See the privacy policy.
