Privacy policy

Last updated: November 2, 2026

This policy covers the "Toggl Track to Sheets" and "Calendly to Sheets" scripts and Google Sheets add-ons (the "tools") made by Wade'a Ahmad ("I").

What the tools access

  • The spreadsheet you install them in. They only use the spreadsheets.currentonly permission, so they can only read and write the spreadsheet you run them from. They write the synced entries or bookings into one tab and read that tab to avoid duplicates.
  • Your Toggl Track or Calendly account, through the API token you paste in. They read time entries, projects, clients and tags (Toggl), or scheduled events and invitees (Calendly). They never create, change or delete anything in those accounts.

Where your data goes

Requests go directly from Google's Apps Script servers, running under your Google account, to Toggl's or Calendly's API. The results are written into your spreadsheet. I don't run any servers. I don't receive, store, sell or share your Toggl, Calendly or spreadsheet data, and I don't use it for advertising or to train AI models.

Your API token is stored in Google Apps Script user properties, which only your Google account can access. Choose Disconnect in the menu to delete it.

Error logs

If a tool hits an error, Google may record the error message in the developer's Google Cloud logs to help fix bugs. These messages describe the error (for example, an HTTP status code). The tools don't log the content of your data.

Google user data

The tools' use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing everything

Choose Disconnect, then uninstall the add-on (or delete the script). The synced data stays in your spreadsheet until you delete it.
