Toggl Track to Google Sheets (free script)

Pulls your Toggl Track time entries into a sheet called Toggl entries, with date, start, stop, hours, duration, description, project, client, tags, billable status, user and entry ID. Re-syncing updates edited entries instead of duplicating them, so you can build invoices and client timesheets with your own formulas and pivots.

A one-click Pro version is planned ($9/month, with a free tier for small accounts). Join the waitlist.

Set it up (about 3 minutes)

  1. Open the Google Sheet you want to use, then choose Extensions > Apps Script.
  2. Delete the sample code, paste the script from the GitHub repository (toggl/Code.gs), and click Save.
  3. Reload the spreadsheet. A Toggl Sync menu appears.
  4. Choose Toggl Sync > Connect Toggl and paste your API token. Find it in Toggl Track under Profile settings > API Token.
  5. Choose Toggl Sync > Sync now. The first time, Google asks you to authorize the script. It only asks to edit the current spreadsheet, connect to Toggl Track's API and run on a schedule.

Good to know

  • The default sync covers the last 30 days. Use Sync a custom date range for up to 365 days at a time.
  • Turn on daily sync refreshes the last 7 days every morning.
  • Toggl's free plan allows about 30 API requests per hour. A typical 30-day sync uses about 5 to 8 (more for very large ranges), so it stays well inside that limit.
  • Works with Toggl Track. Toggl 2.0 uses a different API and isn't supported yet.

Privacy

Your token is saved in your own Apps Script user properties. Use Disconnect in the menu to delete it. See the privacy policy.
