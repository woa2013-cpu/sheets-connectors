Common fixes

  • "rejected the token": create a fresh API token or personal access token and connect again.
  • "hourly limit reached" (Toggl): Toggl's free plan allows about 30 API requests per hour. Wait for the time shown, then sync again.
  • The menu doesn't appear: reload the spreadsheet. For add-ons, look under Extensions.
  • Times look shifted: set your spreadsheet's time zone under File > Settings.
